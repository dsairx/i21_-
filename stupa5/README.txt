ПРАКТИЧНА РОБОТА — БАГАТОВИМІРНИЙ МАКЕТ НА CSS GRID
Варіант 1: Інформаційний портал

ЯК ВІДКРИТИ:
1. Розпакуйте ZIP-архів.
2. Відкрийте папку praktychna_css_grid.
3. Двічі клацніть index.html — сайт відкриється у браузері.
4. Для редагування коду відкрийте index.html та style.css у VS Code.
5. Під час здачі передайте index.html, style.css та папку images.

ЩО ВИКОНАНО:
- Шапка сайту з логотипом і навігацією.
- Основний блок із 9 новинами (мінімальна вимога — 6).
- Головний матеріал займає 2 колонки і 2 рядки (grid-column: span 2; grid-row: span 2).
- Бічна панель із популярними матеріалами та рубриками.
- Нижній колонтитул (footer).
- CSS Grid: display:grid, grid-template-columns, grid-template-rows, grid-auto-rows,
  grid-column, grid-row, gap і grid-template-areas.
- Відносні одиниці fr, minmax() і repeat().
- object-fit: cover для ілюстрацій.
- Адаптивний дизайн: 4 колонки на великому екрані,
  2 на планшеті, 1 на смартфоні.
- Усі ілюстрації локальні, сайт працює без інтернету.

ЯК ПЕРЕВІРИТИ АДАПТИВНІСТЬ:
1. У Chrome відкрийте index.html.
2. Натисніть F12, потім Ctrl+Shift+M (режим мобільних пристроїв).
3. Введіть ширину екрана: 1200 px, 768 px, 375 px.
4. Подивіться, як перебудовуються блоки та сітка новин.

ПОЯСНЕННЯ ДЛЯ ЗАХИСТУ:
- grid-template-columns задає кількість та розміри колонок.
- grid-auto-rows задає висоту створених рядків.
- grid-column: span 2 розтягує елемент на дві колонки.
- grid-row: span 2 розтягує елемент на два рядки.
- grid-template-areas визначає розташування main-content і sidebar.
- @media змінює макет під ширину екрана.
- gap задає відстань між елементами сітки.
- object-fit: cover масштабує зображення до заповнення блоку без спотворення.
